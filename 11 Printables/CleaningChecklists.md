# Printable: Cleaning Checklists
*The "Clean as you Go" Philosophy*

## Daily Reset (The "Closing Shift" - 15 mins)
*Do this every night before bed. Wake up to a clean house.*
*   [ ] **Dishes:** Sink is empty and scrubbed clean. Dishwasher started.
*   [ ] **Counters:** Wiped down (crumb free).
*   [ ] **Floors:** Quick sweep of high-traffic kitchen area.
*   [ ] **Trash:** Taken out if full.
*   [ ] **Hot Spots:** Clear the clutter magnet (entry table / dining table).

## Weekly Deep Clean (The "Power Hour")
*Pick one day (e.g., Saturday Morning).*

### Kitchen
*   [ ] Microwave (steam bowl of water, wipe out).
*   [ ] Stovetop (scrub potential burnt bits).
*   [ ] Fridge (toss expired food, wipe sticky shelves).
*   [ ] Mop floors.

### Bathroom
*   [ ] Toilet (clean bowl and wipe exterior/base).
*   [ ] Sink/Mirror (wipe toothpaste splatters).
*   [ ] Tub/Shower (scrub ring).
*   [ ] Empty trash.

### Living Areas
*   [ ] Dust surfaces (TV, shelves).
*   [ ] Vacuum rugs/carpets.
*   [ ] Wash sheets/towels.

## Seasonal Maintenance (Quarterly)
*   [ ] **Spring (Mar):** Wash windows, deep clean oven, rotation of winter/summer clothes.
*   [ ] **Summer (Jun):** Clean grill, wash deck/patio, AC maintenance.
*   [ ] **Fall (Sep):** Clean gutters, check furnace filter, winterize garden tools.
*   [ ] **Winter (Dec):** Declutter toys/clothes, check smoke detector batteries.
