# Knots, Splices, and Rope Work

**Status:** Placeholder for future content.

## Essential Knots
1.  **Square Knot:** Joining two ropes of equal thickness.
2.  **Bowline:** Creating a fixed loop at the end of a rope.
3.  **Clove Hitch:** Securing rope to a post.
4.  **Taut-Line Hitch:** Adjustable loop for tent lines.
