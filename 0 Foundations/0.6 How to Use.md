# 0.6 How to Use This Suite

## The Workflow
The *Homemaker Suite* is designed to be a loop, not a straight line.

1.  **Assess (Tools & Wizards):** Use the `PantryInventory` and `MealPlanner` to see what you have. (See Series 10)
2.  **Plan (Foundations):** Apply the `Budget Grocery Framework` (See 1.3) to fill gaps.
3.  **Produce (Gardening/Preservation):** Harvest or preserve ingredients. (See Series 4 & 5)
4.  **Execute (Recipes/Cooking Basics):** Cook using the `One Pot Cooking` or specific Recipe files. (See Series 2 & 3)
5.  **Refine (Printables):** Update your inventory and checklist.

## Using the Files
### Markdown (.md)
These are your textbooks. Open them in any text editor, generic Markdown viewer, or specialized knowledge base software (Obsidian, Notion, etc.).
*   *Tip:* Use the Table of Contents or "Find" (Ctrl+F) to locate specific terms (e.g., "internal temp").

### JSON (.json) Tools
These are data structures intended for use with the Homemaker Suite's companion app or any JSON-parsing script.
*   **Don't have the app?** You can still read them! They are text files.
    *   `"ingredients"` lists show what goes in.
    *   `"substitutions"` maps X to Y.
    *   `"ratios"` give you the math for scaling up/down.

### Printables
Located in `11 Printables`.
1.  Open the file.
2.  Print the Markdown rendering (Ctrl+P in most browsers/viewers).
3.  Place in a plastic sheet protector or laminate.
4.  Use a dry-erase marker to check off items.
5.  Wipe clean and reuse.

## Integrating with AI
You are currently using an AI interface to access this suite. You can ask this system to "Run" the tools for you.
*   *Example:* "Using `SubstitutionEngine.json`, what can I use instead of buttermilk?"
*   *Example:* "Run the `PantryCalculator.json` for a family of 4 for 2 weeks."

## Customization
This is *your* suite.
*   **Edit the files.** If you hate cilantro, remove it from the recipes.
*   **Add files.** Create `3.x Grandma’s Pie.md`.
*   **Update Inventory.** Keep your `11 Printables/PantryInventory.md` up to date for the system to work best.

## Emergency Mode
If power/internet goes out:
1.  Ensure you have printed copies of `0.5 Food Safety`, `11 EmergencyReference`, and key recipes.
2.  The "Live Off the Land" philosophy prioritizes manual skills (Series 2) over digital tools for this exact reason.
